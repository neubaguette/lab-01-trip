
# Лабораторна робота №1

**Дисципліна:** Кросплатформне програмування

**Тема:** Базові операції у Java: змінні, методи та класи

**Варіант:** 2 — Trip

## Мета роботи

Налаштувати середовище розроблення Java-проєктів,
реалізувати консольну програму з використанням
класів, методів та змінних, виконати тестування
за допомогою JUnit і забезпечити відтворюване
складання проєкту засобами Maven.

## Програмне забезпечення

- Eclipse Temurin JDK 25.0.4.1 LTS
- Apache NetBeans IDE 31
- Java 21 (цільова версія компіляції)
- Apache Maven 3.9.16
- JUnit Jupiter 6.1.3
- Git

## Завдання

Розробити програму для розрахунку показників
поїздки за трьома вхідними параметрами:

- distanceKm — відстань, км;
- fuelLitres — витрачене паливо, л;
- pricePerLitre — ціна одного літра палива.

Програма обчислює:

1. Витрату палива на 100 км.
2. Загальну вартість палива.
3. Вартість палива на 100 км.

Усі вхідні значення мають бути скінченними
та більшими за нуль.

## Структура програми

- Main.java — введення даних і виведення результатів.
- Trip.java — перевірка параметрів та обчислення.
- TripTest.java — модульні тести JUnit.
- pom.xml — конфігурація Maven.
- submission.properties — номер роботи та варіанта.

## Складання та тестування

Для запуску потрібен JDK 25.
З каталогу проєкту виконати:

```cmd
mvnw.cmd -B -ntp clean verify
```

Очікуваний результат: BUILD SUCCESS.
Усі тести мають завершитися без помилок.

## Запуск програми

Після складання виконати:

```cmd
java -cp target/classes ua.khnu.kpp.lab1.Main
```

Контрольні вхідні дані:

```text
420 31.5 59.9
```

Очікуваний результат:

```text
RESULT_1=7.50
RESULT_2=1886.85
RESULT_3=449.25
```

За некоректного введення програма виводить:

```text
ERROR
```

## Тестування

1. Перевірка контрольних значень.
2. Перевірка альтернативних допустимих значень.
3. Перевірка відхилення недопустимих параметрів.
